# Projeto Escolar: Questionário Escolar em C#

Projeto escolar desenvolvido em C# com o objetivo de criar um questionário interativo para fins educacionais. Este projeto permite que os alunos respondam a perguntas de múltipla escolha e recebam feedback imediato sobre suas respostas.

## Conteúdos utilizados:

- Strings
- Arrays
- Estruturas condicionais
- Estruturas de repetição
- Entrada de dados pelo usuário
- Validação de respostas

## Objetivo do Projeto:

Construir um questionário para que os professores realizem, como um forma de avaliação do conteúdo aprendido pelos alunos.
Desenvolver habilidades de programação em C# e aplicar conceitos de lógica de programação.
